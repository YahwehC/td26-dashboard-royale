# Dashboard Royale (TAMU Datathon 2026) — session notes

Challenge: "Luck, location, or a leak?" — fictional 300-machine casino (The Gilded Ace), Jan–Jun 2025.
GM wants to replace the 10 lowest-earning machines. We decide which are truly bad. Guide: `GUIDE.md`.
User speaks Chinese → answer in Chinese. Code/specs in English.

## Layout
- `data-repo/` — clone of https://github.com/tamu-datathon-org/dashboard-royale (data lives HERE; the
  `dashboard-casino` repo named in the guide does not exist). Read-only, never edit.
- `.venv/` — own venv (Python 3.12). Never use root `.venv`.
- `pipeline/` — Python: build analysis tables + JSON for the dashboard.
- `site/` — static dashboard (HTML+JS, no server) → GitHub Pages. `site/data/*.json` generated by pipeline.
- `specs/` — task specs for DeepSeek (`tools/ds.ps1 -Dir <this folder>`).
- `docs/` — write-up, Claims & Evidence appendix, video script, submission checklist.

## Decisions
- Stack: static single page (vanilla JS + Plotly from cdnjs) on GitHub Pages. Reason: no server to sleep/crash,
  free, public, judges open instantly. User needs a GitHub account + public repo (also required for "all code").
- Period filter is computed client-side from machine×day arrays, so the ranking really changes with the period.
