Cells are (bank, local hour, weekday); the difference within each cell is weighted by the number of treated bank-hours. 95% CI: 1,000 cell bootstraps, seed 42.

The occupancy difference is tiny and positive: bank-hours with a down machine do **not** show a measurable drain of players to neighbours, so substitution does not explain away the downtime estimate.
